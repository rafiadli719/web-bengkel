================================================================================
CATATAN PENTING
================================================================================

PERUBAHAN STRUKTUR:
- tbworkorderheader menggunakan kolom: keterangan, harga, waktu, status
  (bukan: deskripsi_wo, harga_wo, estimasi_waktu, status_wo)

- Tabel stok menggunakan nama: tbstok
  (bukan: tblstokmasuk)

JIKA ADA ERROR:
1. Catat pesan error lengkap
2. Cek nama tabel dengan: SHOW TABLES;
3. Cek struktur tabel dengan: DESC nama_tabel;
4. Sesuaikan query dalam file create_all_views.sql

BACKUP:
Selalu backup database sebelum menjalankan script:
mysqldump -u root -p fitmotor_dbbengkel > backup_$(date +%Y%m%d).sql
