TROUBLESHOOTING
================================================================================

Jika masih error:
-----------------

1. Error "Table doesn't exist"
   → Cek nama tabel: SHOW TABLES LIKE '%nama%';
   → Edit script sesuai nama tabel yang benar

2. Error "Unknown column"
   → Cek struktur: DESCRIBE nama_tabel;
   → Edit script sesuai nama kolom yang benar

3. Error "Foreign key constraint"
   → Script sudah disable foreign key check
   → Jalankan ulang

4. VIEW tidak ada data
   → Cek tabel sumber: SELECT COUNT(*) FROM tblitem;
   → Cek filter WHERE
