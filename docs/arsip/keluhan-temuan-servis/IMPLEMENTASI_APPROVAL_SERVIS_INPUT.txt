Fitur approval keluhan telah berhasil diimplementasikan di halaman Servis Input Reguler.

FITUR YANG DITAMBAHKAN:
1. Modal Search Keluhan - menampilkan keluhan yang sudah approved
2. Tombol "Tambah Keluhan Baru (Perlu Approval)"
3. Modal form untuk ajukan keluhan baru
4. Integrasi dengan master-keluhan-crud.php untuk approval

4. master-keluhan-crud.php
   - Menampilkan keluhan pending
   - Badge notifikasi pending
   - Tombol approve/reject

================================================================================
CARA MENGGUNAKAN:
================================================================================

A. DARI SERVIS INPUT REGULER:

   1. Buka: servis-input-reguler.php
   2. Pilih tab "Work Order"
   3. Klik tombol "Cari Keluhan"
   4. Modal muncul dengan 2 opsi:
      a. Pilih keluhan yang sudah approved
      b. Klik "Tambah Keluhan Baru (Perlu Approval)"
   5. Jika pilih opsi b:
      - Isi form (Nama, Kategori, Deskripsi, Alasan)
      - Submit
      - Alert: "Keluhan berhasil diajukan"
      - Status: PENDING (menunggu approval)

B. APPROVE/REJECT DI MASTER KELUHAN:

   1. Buka: master-keluhan-crud.php
   2. Badge notifikasi: "X Pending Approval"
   3. Alert box kuning muncul
   4. Keluhan pending di baris pertama (highlight kuning)
   5. Klik tombol:
      - Approve (centang hijau) -> Status jadi "Approved"
      - Reject (silang merah) -> Isi alasan -> Status jadi "Rejected"
