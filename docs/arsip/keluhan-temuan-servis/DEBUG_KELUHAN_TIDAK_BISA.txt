================================================================================
STEP 2: Identifikasi Masalah
================================================================================

KEMUNGKINAN 1: Modal tidak muncul
----------------------------------
Gejala: Klik tombol tidak ada reaksi

Cek Console Log:
- Apakah ada error "tambahKeluhanBaru is not defined"?
- Apakah ada error jQuery?

Solusi:
- Refresh halaman (Ctrl+F5)
- Clear browser cache
- Cek apakah jQuery loaded

KEMUNGKINAN 2: Modal muncul tapi submit tidak jalan
----------------------------------------------------
Gejala: Modal muncul, isi form, submit tidak ada reaksi

Cek Console Log:
- Apakah ada error saat submit?
- Apakah AJAX request terkirim?

Solusi:
- Buka Network tab (F12 > Network)
- Submit form
- Lihat request ke ajax-submit-keluhan-baru-debug.php
- Cek response

KEMUNGKINAN 3: AJAX error
--------------------------
Gejala: Alert "Terjadi kesalahan saat mengajukan keluhan"

Cek Console Log:
- Lihat AJAX Error detail
- Lihat response text

Solusi:
- Cek path file ajax-submit-keluhan-baru-debug.php
- Cek session (login ulang)
- Cek database connection

KEMUNGKINAN 4: Validation error
--------------------------------
Gejala: Alert "Gagal mengajukan keluhan: ..."

Cek message:
- "Nama keluhan harus diisi" → Field kosong
- "Kategori harus dipilih" → Kategori kosong
- "Keluhan dengan nama yang sama sudah ada" → Duplicate

Solusi:
- Isi semua field required
- Gunakan nama keluhan yang unik
