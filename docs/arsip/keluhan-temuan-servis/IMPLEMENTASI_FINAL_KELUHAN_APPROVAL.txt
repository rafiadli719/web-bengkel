================================================================================
TROUBLESHOOTING:
================================================================================

Masalah 1: Button tidak berfungsi
----------------------------------
Solusi:
- Refresh halaman (Ctrl+F5)
- Clear browser cache
- Cek console (F12) untuk error

Masalah 2: Modal tidak muncul
------------------------------
Solusi:
- Cek apakah jQuery loaded
- Cek console untuk error
- Pastikan modal-search-keluhan.php ter-include

Masalah 3: Submit tidak jalan
------------------------------
Solusi:
- Cek console untuk AJAX error
- Cek Network tab untuk request
- Pastikan session valid (login ulang)

Masalah 4: Data tidak masuk
----------------------------
Solusi:
- Cek ajax-submit-keluhan-baru-debug.php ada
- Cek database connection
- Cek struktur tabel tbmaster_keluhan
