=====================================================
4. ALUR PENGGUNAAN
=====================================================

A. BUAT PURCHASE REQUEST (PR)
------------------------------
1. User login
2. Menu: Procurement → Purchase Request → Add New
3. Isi form:
   - Tanggal PR: 03/11/2025
   - Tanggal Butuh: 10/11/2025
   - Departemen: Gudang
   - Alasan: Stok menipis
4. Tambah item:
   - Item: Oli Mesin
   - Qty: 10
   - Satuan: Liter
   - Harga Estimasi: 50000
5. Submit PR
6. Status: Submitted (menunggu approval)

B. APPROVAL PR
--------------
1. Supervisor login
2. Menu: Procurement → PR Approval
3. Lihat list PR pending
4. Klik "View" PR yang akan di-approve
5. Cek detail item
6. Klik "Approve" atau "Reject"
7. Isi notes (optional)
8. Submit
9. Status PR berubah: Approved

C. BUAT PURCHASE ORDER (PO) DARI PR
------------------------------------
1. Purchasing login
2. Menu: Procurement → Purchase Order → Create from PR
3. Pilih PR yang sudah approved
4. Sistem auto-fill item dari PR
5. Pilih supplier
6. Isi:
   - Payment Term: Net 30
   - Delivery Address: Alamat gudang
   - Contact Person: Nama & telp
7. Submit PO
8. Status: Pending Approval

D. APPROVAL PO
--------------
1. Manager login
2. Menu: Procurement → PO Approval
3. Lihat list PO pending
4. Cek:
   - Budget available?
   - Harga sesuai?
   - Supplier reliable?
5. Approve atau Reject
6. Status PO: Approved
7. Kirim PO ke supplier (email/print)

E. BUAT DELIVERY ORDER (DO)
----------------------------
1. Supplier konfirmasi pengiriman
2. Warehouse login
3. Menu: Procurement → Delivery Order → Add New
4. Pilih PO yang akan dikirim
5. Isi:
   - No Surat Jalan: dari supplier
   - Tanggal Kirim: 05/11/2025
   - Estimasi Tiba: 06/11/2025
   - No Kendaraan: B 1234 XYZ
   - Nama Pengirim: Budi
   - Telp: 08123456789
6. Isi qty kirim per item
7. Submit DO
8. Status: Confirmed

F. TRACKING PENGIRIMAN
----------------------
1. Menu: Procurement → DO Tracking
2. Pilih DO yang akan di-track
3. Update status:
   - In Transit (05/11 10:00)
   - Arrived at Gate (06/11 08:00)
   - Unloading (06/11 08:30)
4. Isi lokasi & keterangan
5. Status DO: Arrived

G. GOODS RECEIPT (GR)
---------------------
1. Warehouse login
2. Menu: Procurement → Goods Receipt → Create from DO
3. Pilih DO yang sudah arrived
4. QC Check:
   - Cek fisik barang
   - Cek qty
   - Cek kualitas
5. Isi qty terima & qty reject
6. Jika ada reject, isi alasan
7. Submit GR
8. Status QC: Passed/Failed/Partial
9. Stock otomatis update

H. PEMBAYARAN (EXISTING)
-------------------------
1. Finance login
2. Menu: Pembayaran Hutang (existing)
3. Pilih pembelian yang akan dibayar
4. Bayar sesuai term payment
5. Status: Lunas

=====================================================
5. STATUS FLOW
=====================================================

PURCHASE REQUEST (PR):
- Draft → Submitted → Approved/Rejected → Closed

PURCHASE ORDER (PO):
- Draft → Pending → Approved/Rejected → Sent → Confirmed

DELIVERY ORDER (DO):
- Draft → Confirmed → In Transit → Arrived → Received

GOODS RECEIPT (GR):
- Draft → QC Pending → QC Passed/Failed → Posted

=====================================================
7. TIPS & BEST PRACTICES
=====================================================

✅ DO:
1. Selalu buat PR sebelum PO
2. Approval harus lengkap sebelum kirim PO
3. Update tracking DO secara real-time
4. QC check wajib sebelum terima barang
5. Dokumentasi lengkap (foto, surat jalan)

❌ DON'T:
1. Jangan skip approval
2. Jangan terima barang tanpa DO
3. Jangan post GR tanpa QC
4. Jangan bayar sebelum GR
5. Jangan hapus data historical

=====================================================
8. TROUBLESHOOTING
=====================================================

Q: Nomor PR tidak auto-generate?
A: Cek stored procedure sp_generate_no_pr sudah dibuat

Q: Approval tidak muncul?
A: Cek user_akses di tbuser, pastikan ada role approver

Q: DO tidak bisa dibuat?
A: Pastikan PO sudah approved dan sent to supplier

Q: Stock tidak update setelah GR?
A: Cek trigger di tblpembelian_header

Q: Error foreign key?
A: Pastikan urutan import SQL benar, tabel parent dulu
