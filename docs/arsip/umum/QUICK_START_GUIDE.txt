💰 TARIF JEMPUT ANTAR (AUTO-CALCULATE):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MOTOR JALAN:
├─ 0 - 1.0 km → GRATIS
├─ 1.5 km → Rp 8,000
├─ 2.0 km → Rp 10,000
├─ 2.5 km → Rp 12,000
├─ 3.0 km → Rp 14,000
├─ 4.0 km → Rp 18,000
└─ 5.0 km → Rp 22,000

MOTOR MOGOK:
├─ 0 - 1.0 km → GRATIS
├─ 1.5 km → Rp 11,000
├─ 2.0 km → Rp 14,000
├─ 2.5 km → Rp 17,000
├─ 3.0 km → Rp 20,000
├─ 4.0 km → Rp 26,000
└─ 5.0 km → Rp 32,000

Formula:
  Jalan: Base Rp 8,000 + (kelipatan 0.5km × Rp 2,000)
  Mogok: Base Rp 11,000 + (kelipatan 0.5km × Rp 3,000)
