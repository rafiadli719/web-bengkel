PERBAIKAN YANG DILAKUKAN:
-------------------------
1. ✓ Memperbaiki referensi CSS di 2 file:
   - input_kepala_mekanik_harian.php
   - master_kepala_mekanik.php
   Dari: datepicker.min.css
   Ke:   bootstrap-datepicker3.min.css

2. ✓ Membuat 2 tabel database baru:
   a. tbl_master_kepala_mekanik
      - Untuk menyimpan data master kepala mekanik per cabang
      - Kolom: id, kode_cabang, nama_kepala_mekanik, nip_karyawan,
               no_telepon, tanggal_mulai, tanggal_selesai,
               status_aktif, created_by, created_at, updated_at

   b. tbl_kepala_mekanik_harian
      - Untuk menyimpan data kepala mekanik yang bertugas per hari
      - Kolom: id, kode_cabang, tanggal_kerja, kepala_mekanik_1,
               kepala_mekanik_2, shift_kerja, keterangan,
               created_by, created_at, updated_at

3. ✓ Membuat VIEW database:
   - view_master_kepala_mekanik_aktif
     (untuk menampilkan hanya kepala mekanik yang aktif)

CARA MENGGUNAKAN SISTEM:
-------------------------
1. LANGKAH 1: Setup Master Data
   - Buka: master_kepala_mekanik.php
   - Tambahkan data kepala mekanik yang ada di cabang Anda
   - Isi minimal: Nama Kepala Mekanik dan Tanggal Mulai
   - Klik "Simpan"

2. LANGKAH 2: Input Data Harian
   - Buka: input_kepala_mekanik_harian.php
   - Pilih kepala mekanik yang bertugas hari ini (wajib)
   - Pilih kepala mekanik backup jika ada (opsional)
   - Pilih shift kerja (Full Day/Pagi/Siang/Malam)
   - Tambahkan keterangan jika perlu
   - Klik "Simpan Data Hari Ini"

3. LANGKAH 3: Update Data (jika ada perubahan)
   - Jika sudah input hari ini, tombol akan berubah menjadi "Update"
   - Ubah data sesuai kebutuhan
   - Klik "Update Data Hari Ini"
